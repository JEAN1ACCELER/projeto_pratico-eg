# Changelog

Todas as alterações notáveis neste projeto serão documentadas neste arquivo.

## [2.0.0] - 2026-06-30

### Adicionado
- **React + Node.js Full-Stack Implementation**
  - Frontend React 19 com TypeScript e Tailwind CSS 4
  - Backend Node.js com Express e tRPC
  - Banco de dados MySQL/TiDB com Drizzle ORM
  - Autenticação OAuth integrada (Manus)
  - 10 tabelas de banco de dados implementadas
  - Componentes UI com shadcn/ui
  - Testes com Vitest
  - Sistema de upload de arquivos com S3
  - API tRPC type-safe

- **Reorganização do Repositório**
  - Estrutura separada para Flutter (`flutter-app/`) e React (`react-app/`)
  - Documentação unificada
  - Suporte para ambas as tecnologias

### Mantido
- Aplicação Flutter Web original
- Toda a documentação anterior (TP1, TP2, TP3)
- Estrutura de documentação e rastreabilidade

### Melhorado
- README.md com instruções para ambas as aplicações
- Estrutura de pastas mais clara e organizada
- Documentação técnica expandida
