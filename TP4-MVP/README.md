# Trabalho Prático IV - MVP (Produto Mínimo Viável)

## Disciplina: Engenharia de Software I
## Professor: Dr. Andrey Rodrigues, UFAM

Este repositório contém o código-fonte e a documentação do MVP desenvolvido para a disciplina de Engenharia de Software I.

O MVP é um aplicativo mobile desenvolvido com Flutter, seguindo as melhores práticas de engenharia de software, incluindo padrões de projeto, testes automatizados e refatorações.

### Estrutura do Projeto
- `docs/`: Documentação e Mídia
- `lib/`: Código-fonte principal (Flutter)
- `test/`: Testes unitários, de widget e de integração
- `assets/`: Assets (imagens, fontes)

Para mais detalhes, consulte a documentação na pasta `docs/`.
